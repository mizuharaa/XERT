# P1.4 — Official LeRobot ACT reference

**Measured MuJoCo result:** see the [ledger-generated comparison](../../results/p1.4/official_act_v1/comparison.md)
for official ACT (training seeds 0, 1, 2: ledger rows `15103d29-afdb-4853-8e63-717e448723ba`,
`93e321d8-0b9c-49d0-9692-b6ecb8af6909`, `18dee197-8c4f-43ae-8324-0a1b996e2dbf`)
against the existing ACT-style models on the same states (the P1.3 rows). It
links every row and its separate Wilson interval. This bounded run shows variation
across seeds, which also change the episode split; it does not identify a cause
or establish general superiority. The protocol and source were frozen at `0c26610`.

The reference uses LeRobot's installed ACT policy, an action chunking transformer:
it predicts several future joint commands together. The existing ACT-style model
and this reference receive the same scripted recovery demonstrations. Exported
LeRobot arrays must match the verified NPZ corrective labels exactly.

The adapter partitions the full simulator observation into joint positions and
velocities, and the remaining world, task and time values. Those privileged
values come directly from the simulator. Nothing is silently removed or replaced
with camera data. Mean and standard deviation are calculated only from training
episodes, excluding terminal observations with no action target, and must match
the original model's saved statistics. Actions keep their normalized target units.

The [committed protocol](../../configs/lerobot_act_experiment.json) fixes three
training seeds, the original episode splits, the same final epoch budget, and the
chunk length previously selected using validation data. Checkpoints are selected
only by prior-inference validation action error: the variational encoder receives
no future action labels during that comparison. Held-out evaluation uses the
same reset seeds and checks the actual initial-state hashes across dependency
stacks before training. A hash is a fingerprint of the exact array bytes.

The small network settings bound CPU work. This is an official implementation
reference with explicit settings, not a claim that the full default architecture
was trained to convergence. Official temporal ensembling averages overlapping
predictions, favoring older predictions; the earlier model favors newer ones.
Both query each control tick and clear their prediction buffer every episode.
Official ACT emits unrestricted linear outputs; the earlier model applies tanh,
which bounds predictions. Validation scores each model's unchanged predictions;
execution clips commands to the existing target limits. Architecture and library
versions also differ, so this comparison cannot isolate one change. Installed
official source hashes are retained. No scripted policy rescues failed rollouts.

The runner writes separate Wilson confidence intervals for each model: a range
expressing uncertainty in its success probability under the sampled simulation
conditions. Shared evaluation states are not pooled as independent extra trials.
The comparison table is generated from ledger rows. Failed experiments retain
their artifacts; an existing output directory is never reused.

**Interview question:** Why not use the exported dataset's normalization statistics?
**Answer:** They include validation episodes, so using them would leak held-out
information into training and change the comparison with the existing model.

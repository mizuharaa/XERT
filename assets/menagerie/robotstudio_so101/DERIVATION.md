# Local adaptation

`so101.xml`, its referenced meshes, `README.md`, and `LICENSE` are unchanged
upstream bytes. `SOURCE.json` records their immutable commit and SHA-256 hashes.

`so101_xert.xml` is generated by `scripts/prepare_so101.py`. It adds only the
`grasp` site at the existing `fixed_jaw_sph_tip1` position and formats XML.
The source model's kinematics, dynamics and geometry are unchanged.

This is an actual Robot Studio SO101 model. It does not replace or rename the
older XLeRobot arm used by the existing manipulation-learning benchmark.
